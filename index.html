01 / Open-source Android

Built for Android.
Shared with developers.

Three libraries I maintain to make everyday
Android development more considered.

Jetpack Compose / Notifications

SnapNotify

A clearer way to say “saved.”

Show in-app snackbars from Composables or ViewModels without passing host state through your app. A shared queue, semantic styling, action callbacks, and scoped channels keep notifications organized.

Compose snackbars · Scoped queues · Undo actions

Featured in Android Weekly #692 ↗ Explore SnapNotify ↗

Kotlin / Runtime permissions

EasyAndroidPermissions

Permission flows that read naturally.

Request Android permissions with Kotlin suspend functions and a shared API for Compose, Activities, and Fragments. Observe permission state and handle grants, denials, and rationale through lifecycle-aware integration.

Coroutines · Compose & Views · Permission state

Featured in Android Weekly #694 ↗ Explore EasyAndroidPermissions ↗

Gradle / Library quality

ShrinkGuard

Make shrinking changes reviewable.

Review what R8 retains, renames, and removes before publishing a Kotlin or Android library. ShrinkGuard compares a synthetic consumer report with a committed baseline and lints consumer keep rules.

R8 reports · Baseline checks · Keep-rule lint

Designed to complement release-app testing.
